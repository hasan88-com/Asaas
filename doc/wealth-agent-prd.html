01

Problem & opportunity

Retail investors in Pakistan have capital and intent but no accessible way to build and manage a diversified portfolio across the asset classes available to them.

Existing tools either track a single asset class, assume a sophistication the average user lacks, or are priced for institutions. Meanwhile the data that would power a good advisor — PSX prices, SBP rate moves, dividend announcements, commodity trends — is scattered, partly free, and never assembled into one decision-making view. The investor is left reacting to news they may not even know affects their holdings.

  • Fragmented data. PSX, T-bills, commodities, and crypto each live behind different sources with different access models.
  • No personalization. Generic market news isn't filtered to what a specific person actually holds.
  • No continuity. Tools recommend once and stop; nobody watches the portfolio after the money is in.
  • Local constraints ignored. Most models use a 0% risk-free rate; in Pakistan, the SBP policy rate is a dominant factor that changes every allocation.
Opportunity

A single agent that ingests the available free data, reasons over it with real portfolio theory tuned to Pakistan, and stays on as a persistent monitor — doing the analytical work continuously while leaving every decision with the user.

02

Product vision

A conversational advisor that profiles you, proposes a portfolio, and then watches the market for you — like a diligent analyst who only ever recommends, and waits for your call.

The user talks to the agent in plain language. The agent profiles their risk, horizon, and capital; pulls candidate assets; runs portfolio optimization with diversification and risk constraints tuned to the local market; and returns a suggested allocation with a plain-language rationale. Once the user confirms what they actually invested, the agent shifts into a monitoring role: it tracks news against those exact holdings, scores each event for materiality, and flags only what genuinely changes the portfolio's risk or return. When something material hits, the user — not the agent — decides whether to re-optimize.

North-star principle

Autonomous analysis, human-approved decisions. The agent does all the watching, matching, and computing on its own. It never moves money or rebalances without the user pressing the button.

The product serves two investor postures. The agent classifies which the user is during onboarding and adapts its logic, data cadence, and recommendations accordingly.

Honest scoping note

True intraday day trading needs tick data that isn't freely available for PSX. "Active" mode is deliberately built on daily candles and framed as short-term/swing — an honest scope given the data, rather than implying live tick feeds the system doesn't have.

04

The agent lifecycle

The agent moves through three phases. This lifecycle is the product — each phase has distinct responsibilities and a distinct portfolio state.

PHASE 01

Onboarding

User fills a form / chats. Agent profiles them, pulls candidate assets, runs optimization, and suggests a portfolio with rationale. State: draft.

PHASE 02

Activation

User confirms what they actually invested (may differ from the suggestion). Agent locks the real holdings and begins tracking. State: confirmed.

PHASE 03

Monitoring

Background jobs watch news and prices against confirmed holdings, score materiality, and flag. User triggers any re-optimization. State: tracked.

Why state matters

The agent monitors the confirmed portfolio, not the suggestion. Users rarely buy exactly what's proposed, so the system must store actual positions as the source of truth for all tracking and performance.

06

News & materiality flow

The monitoring engine's core logic. Raw news is noise; the agent's real job is filtering to what affects this user's holdings, then deciding whether it's actionable or merely informational.

Three levels of relevance

LevelTriggerExample
DirectNews names a ticker the user holds"HBL announces record profits" → user holds HBL
SectorNews affects a sector the user is exposed toSBP raises rates → user holds bank stocks
MacroPortfolio-wide effectPKR depreciates 5% → affects everything
Fixed-income depth

For T-bills the agent encodes the inverse rate relationship: rates up → existing bond prices down, new issues yield more. An SBP rate cut prompts "your T-bills just appreciated"; a hike prompts "market value may dip, but reinvestment yield improves." Getting this relationship right is what makes the fixed-income guidance trustworthy.

Data layer

Each asset class gets a refresh strategy matched to how fast it actually moves and how its data is available. This keeps the system within free-tier limits.

Asset classPrimary sourceFallbackRefresh
Global stocksyfinance—Daily EOD
PSX stocksyfinance .KAPSX DPS scrapeDaily EOD
CryptoCoinGeckocached value30–60s cache
T-billsSBP scrape—Event-driven
Commoditiesyfinance + FREDAlpha VantageDaily + on-demand news
Key simplification

yfinance carries PSX stocks via the .KA suffix (NBP.KA, PSO.KA, HBL.KA…), so it drives global stocks, PSX stocks, and commodities through one adapter. PSX scraping is demoted to a targeted fallback for freshness checks, missing tickers, and dividends — far less fragile than a scrape-first pipeline.

Refresh orchestration

  • Daily (after close): yfinance EOD for stocks + commodities → recompute portfolio values + write a daily snapshot.
  • Frequent / on-load: CoinGecko crypto, batched and cached 30–60s.
  • Event-driven: T-bill scrape on new bond announcement or 3-month timer; rate-impact analysis on SBP rate news.
  • On-demand: commodity news when the user asks; full portfolio refresh on request.

LLM routing

The agent runs free-first, routing each call to the provider best suited for it. High-stakes data privacy is handled by keeping real financial PII out of free tiers.

JobProvider / modelWhy
Reasoning & analysisGemini 2.5 Flash1,500 req/day, 1M tokens/min — handles large news + portfolio context
User-facing chatGroq (Llama 3.3 70B)Fastest inference; low latency for conversation
News sentiment (bulk)Gemini Flash-Lite / Groq 8BCheap, fast, high volume
Rate-limit fallbackOpenRouter free slotRe-route when a primary provider caps out
Privacy guardrail

Gemini's free tier may use prompts for training. The agent reasons over abstracted data (ticker + weight, not real account IDs or balances) — consistent with the platform's privacy-by-architecture principle. Verify current free-tier quotas before building; providers change them often.

Reference walkthrough

Fill form → get suggested portfolio → confirm → a material news event (e.g. an SBP rate decision) → agent flags it with impact analysis → user triggers re-optimize → agent shows the adjusted portfolio. This single loop exercises every core part of the product end to end.

Why start with liquid names

Thinly-traded PSX stocks have gappy history → unstable covariance matrices → garbage optimization. Starting with the most liquid 30–50 KSE-100 names gives clean correlations, stable optimization, and reliable output. Quality over coverage.

Non-negotiable

The agent suggests; the user decides. No automatic rebalancing, no trade execution without explicit confirmation. This is both a trust requirement and a compliance one.
